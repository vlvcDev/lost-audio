# Built-in guitar DI test audio

`guitarjam-184.wav` is clip `184.wav` from the GuitarJam dataset by Julian-br.
It is a raw, mono electric-guitar direct-input recording made with a Fender
Stratocaster and Focusrite Scarlett Solo. The original is 44.1 kHz, 16-bit PCM.

Source: https://huggingface.co/datasets/Julian-br/GuitarJam

License: Creative Commons Zero v1.0 Universal (CC0-1.0)
https://creativecommons.org/publicdomain/zero/1.0/

The file is redistributed unmodified. The engine resamples it in memory for
48 kHz preview rendering.
